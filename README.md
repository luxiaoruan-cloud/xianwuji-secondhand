# 闲物集 · 二手闲置交易网站

一个美观、响应式的二手闲置物品交易演示网站。

## 在线预览

请到仓库 **Settings → Pages** 启用 GitHub Pages（Source: Deploy from a branch, Branch: main / root），然后访问：

**https://luxiaoruan-cloud.github.io/xianwuji-secondhand/**

## 功能亮点

- **首页**：精美 Hero、分类筛选、商品瀑布流、搜索
- **商品详情**：弹窗展示，支持「我想要」
- **发布闲置**：完整表单，发布后立即出现在首页（本地存储）
- **购物车/想要清单**：侧边栏管理想要的物品
- **完全响应式**：手机、平板、电脑都适配良好
- **中文界面**：专为中文用户设计

## 本地使用

下载 ZIP 或 clone 后，直接用浏览器打开 `index.html` 即可。

## 技术栈

- HTML5 + Tailwind CSS (CDN)
- 原生 JavaScript
- LocalStorage 存储用户发布的商品和购物车

本项目为前端演示，没有真实后端和支付。
